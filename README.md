# AIGC Public Course HTML PPT

A static web presentation for a 2-hour public course on AIGC: AI basics, LLM intuition, AI image generation, AI video generation, AI comic drama workflow, and Beijing Universal Resort IP opportunities.

## Preview

Open `index.html` directly or deploy the repository as a static site on Vercel.

## Files

- `index.html`, `styles.css`, `script.js`: web presentation runtime
- `data/slides.js`: slide content data
- `assets/`: selected video frames and GIF clips used in the deck
