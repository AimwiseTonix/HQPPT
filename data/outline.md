# AIGC 2小时公开课逐页大纲 v1

课程定位：面向非技术/泛内容行业听众的公开课。目标不是训练工程师，而是让听众理解 AIGC 的底层逻辑、能力边界和文旅 IP 内容机会。

课程主线：AI 如何从理解文本，发展到生成图像、生成视频，并最终形成 AI 漫剧内容生产线。

参考来源：Transformer 视频、AI 绘画视频、AI 视频视频、AIGC 漫剧赋能北京环球参考 PPT。

## 1. AI基础大白话：先把名词讲明白

| 页码 | PPT标题 | 核心要讲什么 |
|---:|---|---|
| 5 | AI 到底是什么 | AI 不是机器人，也不是搜索框，本质是从大量例子里学规律，再用规律处理新问题。 |
| 6 | 模型是什么 | 模型可以理解为“被训练出来的经验系统”：输入一个东西，它根据经验给出判断或生成。 |
| 7 | 数据是什么 | 数据就是模型见过的例子。文本、图片、视频、声音都可以成为训练素材。 |
| 8 | 参数是什么 | 参数不是资料库，而是模型在训练中留下的“经验痕迹”。模型能力藏在参数组合里。 |
| 9 | 训练是什么 | 训练像反复做题：模型先答，再对答案，再改错，重复很多次。 |
| 10 | 推理是什么 | 推理是训练结束后的使用阶段：参数固定，用户输入问题，模型给出结果。 |
| 11 | 生成式 AI 和传统 AI 有什么不同 | 传统 AI 更像判断题；生成式 AI 会补全文本、生成图片、生成视频。 |
| 12 | 为什么 AI 会“看起来像懂了” | 因为它在海量样本中学到了关系：词和词的关系、图和词的关系、动作和时间的关系。 |
| 13 | AIGC 的三个共同动作 | 先把输入变成数字表示，再计算关系，最后生成新的内容。文本、图像、视频都绕不开这三步。 |
| 14 | 这一章只记住一句话 | AI 不是临时查答案，而是用训练好的经验，把输入转成可计算的表示，再生成输出。 |

## 2. LLM：机器如何理解一句话

| 页码 | PPT标题 | 核心要讲什么 |
|---:|---|---|
| 15 | 语言为什么难 | 一句话不是字词堆叠，同一个词在不同上下文里含义会变化。 |
| 16 | 中文案例：用毒毒毒蛇，毒蛇会不会被毒死？ | 用这个例句说明：同一个“毒”，可能是手段、动作、属性、结果的一部分。 |
| 17 | 人为什么能看懂 | 人会自动看上下文：前后词、语法位置、常识关系共同决定含义。 |
| 18 | 机器第一步：把句子切成小块 | Token 是模型处理语言的基本单位；有时是字，有时是词，有时是词的一部分。 |
| 19 | 机器第二步：把文字变成数字 | 模型不能直接理解文字，需要把 token 变成数字向量。 |
| 20 | 向量可以理解成语义地图坐标 | 相似用法在向量空间里更接近，不是人工写规则，而是训练中形成的位置关系。 |
| 21 | 机器第三步：判断该看谁 | 模型理解一个词时，不是平均看全句，而是判断哪些词对当前词更重要。 |
| 22 | 图书馆类比：每个词都带着问题找资料 | 当前词像带着问题进图书馆，去匹配最有帮助的“书”。 |
| 23 | 图书馆类比：不是每本书都读一样久 | 重要信息多读，不重要信息少读；这就是注意力的直觉。 |
| 24 | LLM 到底在生成什么 | 它根据前文和上下文关系，预测下一个最合理的 token。 |
| 25 | 为什么 LLM 能写总结、回答问题 | 因为它不只学词，还学到了大量表达结构、知识关联和任务格式。 |
| 26 | LLM 的边界在哪里 | 它可能编造、不知道最新事实、对复杂现实缺乏真实经验，所以需要校验和约束。 |
| 27 | 从文本到图像的桥 | 如果文字能变成向量，那么图片也能变成向量；下一章就看文字如何控制图像。 |

## 3. AI绘画：文字如何变成图像

| 页码 | PPT标题 | 核心要讲什么 |
|---:|---|---|
| 28 | AI 绘画不是“图库拼贴” | 它不是从网上找一张图贴出来，而是在提示词条件下生成新图像。 |
| 29 | 早期 AI 绘画为什么很怪 | 画面糊、结构乱、文字错，是因为模型还不能稳定理解语义和空间关系。 |
| 30 | 图像生成的核心难题 | 一张图同时有主体、背景、构图、光影、材质、文字、风格，约束非常多。 |
| 31 | 扩散模型的直觉 | 先把清晰图片加噪声，再训练模型学会一步步去噪。 |
| 32 | 生成时从噪声开始 | AI 不是从空白画布画起，而是从随机噪声里逐步还原出符合条件的画面。 |
| 33 | U-Net 像一台图像修复器 | 它每一步都判断：当前画面里哪些是噪声，哪些应该保留。 |
| 34 | 提示词不是命令，是生成方向 | prompt 会被转成向量，用来影响去噪过程，让图像往目标语义靠近。 |
| 35 | 文本和图像要先对齐 | 模型需要知道“文字描述”和“视觉内容”如何对应，否则提示词再精确也指挥不动图像。 |
| 36 | CLIP/多模态模型像翻译官 | 它把文字翻译成图像模型能理解的语义信号。 |
| 37 | 为什么早期提示词不听话 | 文字和图像只是粗略关联，复杂关系、数量、空间位置容易丢失。 |
| 38 | 多模态大模型让提示词更可控 | 更强的文本理解能力，让模型能处理更复杂的描述和关系。 |
| 39 | 画面布局为什么会乱 | 局部去噪容易只看眼前区域，缺少全局结构意识。 |
| 40 | DiT/全局注意力解决什么 | 让图像中的不同区域互相建立关系，画面布局更统一。 |
| 41 | 为什么数据标注很重要 | 模型不是凭空变聪明，高质量图文标注让它知道图片里到底有什么。 |
| 42 | AI 自动标注让训练材料更细 | 用更强模型给图片写详细描述，提升模型对复杂提示词的理解。 |
| 43 | 为什么 AI 以前写不好字 | 文字对图像模型来说是精确结构，不是普通纹理，错一笔就不像字。 |
| 44 | 文字生成的改进思路 | 与其让模型凭空猜字形，不如给它更明确的位置、版式或模板约束。 |
| 45 | 局部重绘解决什么 | 不用整张图重画，只修改被圈定的区域，让修改更稳定。 |
| 46 | 语义分割让模型知道改哪里 | 自动识别主体边界，避免传统抠图白边和光影不一致。 |
| 47 | 潜空间编辑为什么更自然 | 在抽象空间里修改材质、光线和结构，比直接改像素更容易保持一致。 |
| 48 | AI 绘画从玩具变成工作流 | 文生图、图生图、局部重绘、风格统一、角色设定共同组成生产链。 |
| 49 | AI 绘画适合做什么 | 概念图、海报草图、角色设定、分镜、视觉风格探索、营销素材。 |
| 50 | AI 绘画不适合直接交付什么 | 强版权 IP、绝对精确文字、严肃商业物料仍需要人工审核和后期。 |
| 51 | 这一章的结论 | AI 绘画的进步，不是“画得更炫”，而是语义理解、布局控制、局部修改越来越稳。 |

## 4. AI视频：为什么从崩坏走向流畅

| 页码 | PPT标题 | 核心要讲什么 |
|---:|---|---|
| 52 | AI 视频为什么比 AI 绘画难很多 | 视频多了时间：同一个人、同一个物体，要在连续画面中保持一致。 |
| 53 | 早期 AI 视频为什么崩坏 | 如果逐帧生成，每一帧都像单独画图，人物和场景会闪烁、变形、跳变。 |
| 54 | 视频不是图片序列，而是时空整体 | 更合理的理解是：视频是一块包含宽、高、时间的三维时空块。 |
| 55 | 三维时空块的直觉 | 模型不只看一张画面，而是同时考虑前后帧之间的关系。 |
| 56 | 视频 token 是什么 | 把视频切成很多小块，每个小块都变成模型能计算的 token。 |
| 57 | 自注意力让画面建立全局关系 | 不同时间、不同位置的视频块互相交换信息，减少闪烁和变脸。 |
| 58 | 流畅的关键是帧间一致性 | 人脸、衣服、场景、光线不能每一帧都重新随机生成。 |
| 59 | 提示词如何控制视频 | 交叉注意力让视频块参考文字或参考图，从而生成指定内容。 |
| 60 | 参考图为什么重要 | 它能锁定角色长相、服装、风格，减少每段视频都变一个人的问题。 |
| 61 | 首尾帧控制是什么 | 给模型明确开头和结尾，帮助它生成中间过渡动作。 |
| 62 | 姿态控制解决什么 | 用动作骨架、镜头参数、运动轨迹告诉模型“怎么动”。 |
| 63 | 物理感为什么难 | 光靠视频数据，模型很难真正理解重力、碰撞、速度和惯性。 |
| 64 | 物理一致性的训练思路 | 用模拟数据、判别器或强化学习，让模型更接近真实物理规律。 |
| 65 | 镜头控制为什么是高级能力 | 推、拉、摇、移、环绕不是简单运动，而是主体、背景、透视一起变化。 |
| 66 | 长视频为什么难生成 | 时间越长，计算量越大，角色和场景越容易漂移。 |
| 67 | 分段生成如何保持一致 | 用上一段最后画面、角色参考、场景参考，约束下一段继续生成。 |
| 68 | 音画同步为什么关键 | 真正的短剧不只是画面，还需要台词、口型、情绪和节奏同步。 |
| 69 | 原生多模态视频的方向 | 未来视频和音频会一起建模，而不是先画面后配音。 |
| 70 | AI 视频适合做什么 | 概念短片、动态分镜、广告预演、社媒短内容、虚拟角色内容。 |
| 71 | AI 视频当前不适合什么 | 长篇稳定叙事、复杂多人互动、严格动作连续、强 IP 商用仍需谨慎。 |
| 72 | 这一章的结论 | AI 视频的核心不是“让图片动”，而是让画面在时间里保持逻辑一致。 |

## 5. AI漫剧：把文本、图像、视频连成生产线

| 页码 | PPT标题 | 核心要讲什么 |
|---:|---|---|
| 73 | AI 漫剧是什么 | 用 AIGC 参与剧本、角色、分镜、画面、视频、配音、剪辑的短内容生产方式。 |
| 74 | AI 漫剧不是单一工具产物 | 它是 LLM、AI 绘画、AI 视频、配音、剪辑、运营共同组成的工作流。 |
| 75 | 第一步：选题和故事框架 | 用 LLM 辅助生成题材方向、人物关系、冲突结构和集数规划。 |
| 76 | 第二步：角色和世界观设定 | 用图像模型生成角色形象、服装、场景、视觉风格。 |
| 77 | 第三步：分镜和画面资产 | 把剧本拆成镜头，生成关键画面，形成可复用素材库。 |
| 78 | 第四步：视频化和镜头运动 | 用 AI 视频把关键帧变成短镜头，再通过剪辑形成节奏。 |
| 79 | 第五步：声音和后期 | 配音、口型、音效、字幕、BGM 决定短剧是否真正可看。 |
| 80 | AI 漫剧的优势 | 降低试错成本、缩短制作周期、提高选题测试速度。 |
| 81 | AI 漫剧的风险 | 版权、IP 授权、肖像、内容合规、AI 标识、质量稳定性。 |
| 82 | 这一章的结论 | AI 漫剧不是让 AI 一键拍剧，而是把内容生产拆成多个可控环节逐步提效。 |
