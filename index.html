Transformer / Long Form

从一句绕口中文
彻底理解 Transformer

全黑极简版：把视频内容拆成 6 个大章节、51 页细讲。每一步先讲人话，再落到数学结构。

用毒毒毒蛇，毒蛇会不会被毒毒死？
Chapter 1

为什么这句话难？

同一个“毒”在不同位置会扮演不同角色。Transformer 的第一性问题就是：如何让机器找出字词之间的关系。

01 / 例句

用毒毒毒蛇，毒蛇会不会被毒毒死？

人能根据上下文猜出：有的“毒”像动作，有的“毒”像属性，有的“毒”又参与“毒死”这个结果。

但计算机一开始只看到符号序列。它不知道哪个“毒”和哪个“毒蛇”相关，也不知道“毒死”应该被看作一个结果。

用
毒
毒
毒蛇
毒蛇
被
毒
毒死
02 / 同字不同义

难点不是“毒”字，而是“毒”在句子里的位置

单独拿出一个“毒”，机器无法判断它是名词、动词、形容词，还是词组的一部分。

所以理解语言不能只看一个 token 本身，必须看它和周围 token 的关系。

毒动作：用毒
毒属性：有毒
毒蛇实体：一种蛇
毒死结果：被毒死
03 / 关系才是语义

每个字都和其他字相互关联

“用”会更关心后面的“毒”；“毒蛇”会关心前面的修饰和后面的动作；“毒死”会关心“被”和施加动作的“毒”。

Transformer 的核心思想，就是把这种关联变成一个可训练、可计算的权重矩阵。

04 / 本质目标

从“文字”到“关系矩阵”

机器无法直接理解中文，但可以处理数字、向量、矩阵和概率。

所以整条路线是：文字先变成向量，再让向量之间互相打分，最后用分数决定谁影响谁。

文字 → token → 向量 X → 关系权重 A → 新向量 Z
Chapter 2

输入预处理：把文字变成模型能算的东西

视频前半段很关键：Transformer 不是直接理解文字，而是先完成 token、embedding、position 三步。

05 / Token

第一步：分词，把句子拆成 token

视频里提到 BPE 这类分词工具。它会把句子拆成最小语义单位，不一定等于一个汉字，也不一定等于一个完整词。

比如“毒蛇”“毒死”可能作为更稳定的片段出现，而不是永远拆成单字。

用毒毒毒蛇，毒蛇会不会被毒毒死？
06 / Token ID

第二步：每个 token 映射成词表编号

模型真正接收的不是“毒蛇”两个字，而是词表中的一个整数编号。

这一步像把文字贴上条形码：条形码本身没有语义，但它能索引到下一步的向量。

07 / Embedding

第三步：编号变成 512 维词向量

视频里说，一个 token 可以被编码成 512 维向量。你可以把它理解成 512 个数字组成的语义坐标。

它不是人工写死的解释，而是在训练过程中不断调整出来的。

08 / 向量意义

向量不是翻译，而是“可计算的语义位置”

相近含义的 token，向量可能更接近；不同语法角色的 token，向量会在不同维度上呈现差异。

模型不会说“这一维表示毒性”，但训练会让这些维度整体服务于预测任务。

xi ∈ ℝ512
X ∈ ℝn×512
09 / Position

第四步：加入位置编码

Transformer 会把多个向量同时送入模型，这带来并行优势，但也让模型天然不知道先后顺序。

因此要给每个 token 加上位置编码，告诉模型谁在前、谁在后。

10 / 位置公式

位置编码可以用 sin / cos 表达

经典 Transformer 使用不同频率的正弦、余弦曲线，让每个位置都有独特“指纹”。

直觉上，它像给每个 token 发一个座位号。

PE(pos,2i)=sin(pos/100002i/d)
PE(pos,2i+1)=cos(pos/100002i/d)
Chapter 3

Q / K / V：让每个 token 会提问、会被检索、会贡献内容

这是视频前半部分最关键的桥。后面的注意力公式，全部建立在 Q、K、V 三种身份上。

11 / 三种身份

同一个 token，会被投影成 Q、K、V

输入向量 X 会分别乘三个权重矩阵 WQ、WK、WV。

于是每个 token 都得到三份不同用途的向量：查询、键、值。

12 / Query

Q：我现在想找什么信息？

Query 表示当前 token 的“问题”。比如“用”这个 token 可能想知道后面用的是什么，“被”可能想知道谁对谁做了什么。

通俗说，Q 是检索请求。

Q = XWQ
13 / Key

K：我能被什么问题匹配？

Key 像标签或索引，告诉其他 token：“如果你在找这类信息，可以来匹配我。”

视频里的说法很贴切：K 可以看作书的标签或索引。

K = XWK
14 / Value

V：我真正贡献的内容

Value 才是最后要被读取、加权、汇总的信息本身。

Q 和 K 负责决定“读谁”，V 负责提供“读到什么”。

V = XWV
15 / 图书馆类比 1

把你想象成一个 token，带着问题走进图书馆

你手上的问题就是 Q。你不是随机读书，而是先看每本书的索引标签。

这些索引标签就是 K。它们帮助你判断哪本书更可能回答你的问题。

16 / 图书馆类比 2

匹配度越高，你花的阅读时间越多

Q 和 K 的相似度，就是你和这本书标签的匹配度。

匹配度高的书，你会多读；匹配度低的书，你会少读甚至不读。

score(q,kj) = q · kj
17 / 图书馆类比 3

最后你带走的不是一本书，而是整合后的理解

你按不同权重阅读不同书的内容 V，最后脑子里形成新的知识。

这就对应注意力输出：按权重加权汇总所有 V，得到新的 token 表示。

z = Σj attentionj · vj
Chapter 4

Self-Attention：自己和自己产生注意力

现在进入核心公式。每个 token 都拿自己的 Q，去和全句所有 token 的 K 做匹配，再按权重读取 V。

18 / 相似度打分

第一步：Q 和 K 做点积

点积越大，说明当前 Query 和某个 Key 越匹配。

在例句中，“用”可能更关注后面的“毒”；“被”会关注动作和结果。

19 / 缩放

第二步：除以 √dk，防止分数过大

维度越高，点积值越容易变大。分数太大时，softmax 会过于尖锐，训练不稳定。

所以公式里要除以 √dk。

scores = QKT / √dk
20 / Softmax

第三步：把分数变成权重

softmax 会把一行分数变成 0 到 1 之间的比例，并且总和为 1。

这行比例就表示当前 token 对其他 token 的关注程度。

21 / 加权汇总

第四步：用权重读取 V

现在模型知道该关注谁了，但还需要把那些 token 的内容真正吸收进来。

所以每个 V 会乘以注意力权重，再整体求和。

Attention(Q,K,V)=softmax(QKT/√dk)V
22 / 矩阵视角

一行权重，就是一个 token 的关注分布

注意力矩阵的第 i 行，表示第 i 个 token 对所有 token 的关注比例。

整张矩阵则表示全句所有 token 之间的关系网络。

23 / Self-Attention 的意义

每个 token 都获得了“上下文后的新理解”

经过自注意力后，“毒”不再只是一个孤立符号，而是带着它在这句话里和其他 token 的关系。

视频里把这组新向量叫作对其他 token 的抽象理解。

X → Attention → Z
Z 包含上下文关系
24 / 为什么要多头？

一个头只能学一种视角

句子里的关系不是单一的：有动作关系、修饰关系、指代关系、情绪关系、远距离依赖。

一个注意力头可能不够，所以 Transformer 并行使用多个头。

25 / 多头数学

512 维拆成 8 个 64 维头

视频中举例：512 维向量可以拆成 8 个 64 维向量，每个头独立做一次注意力计算。

最后再把 8 个头的结果拼接回来，重新得到 512 维表示。

headi = Attention(Qi, Ki, Vi) Qi=XWiQ　Ki=XWiK　Vi=XWiV MHA = Concat(head1 ... head8)WO
Chapter 5

Encoder：让理解变深

多头注意力之后，还要加残差、归一化和前馈网络。它们解决的是深层网络稳定性和非线性表达能力。

26 / Encoder Block

一个 Encoder 层通常包含四步

Multi-Head Attention、残差连接、LayerNorm、Feed Forward Network。

这一层的目标，是让每个 token 表示变得更懂上下文。

27 / 残差连接

F(X)+X：给信息一条直通路

视频里解释得很直观：如果某层最优解是什么都不做，F(X) 可能接近 0。

但只要输出是 F(X)+X，原始 X 就还能继续往后传，深层网络更容易训练。

Y = X + F(X)
28 / LayerNorm

归一化：让数值尺度更稳定

每层输出的数值可能波动很大。归一化会把数值拉回稳定范围，减少训练不稳定。

严格说 LayerNorm 不只是简单压到 0 到 1，但它的直觉就是统一尺度。

LN(x) = γ · (x-μ)/√(σ²+ε) + β
29 / FFN

前馈网络：给每个位置做非线性加工

注意力负责交换信息，FFN 负责让每个 token 的表示变得更复杂。

视频里用曲线类比：没有非线性，模型只能表达比较简单的线性关系；激活函数让它能拟合复杂形状。

FFN(x)=W2 · ReLU(W1x+b1) + b2
30 / 多层堆叠

一层理解局部，多层理解更深语义

单层多头注意力处理一句话勉强够用，但长段落、复杂语义需要多层结构。

多层 Encoder 会逐步把浅层词义加工成更抽象的语义表示 Xout。

X → Encoder1 → ... → EncoderN → Xout
Chapter 6

Decoder：根据理解逐词生成

视频后半段讲生成。Decoder 的核心是：瞻前顾后。看 Encoder 理解到的输入，也看自己已经生成的输出。

31 / 两个输入

Decoder 同时接收两类信息

第一类是 Encoder 输出 Xout，它代表模型对原句的理解。

第二类是已经生成的 token 序列，它代表当前写到哪里了。

Decoder input = Xout + y<t
32 / 逐词生成

模型不是一次生成整句，而是一次预测一个 token

每生成一个新 token，就把它接到已有序列后面，再用新的序列预测下一个 token。

这个循环一直持续到生成结束符。

33 / Masked Self-Attention

训练时不能偷看未来答案

训练时答案序列是完整的，但 Decoder 在第 t 步只能看到 y<t。

所以要把未来位置设为 -∞，softmax 后这些位置权重变成 0。

34 / 为什么要 Mask

保证训练和真实使用一致

真实使用时，未来 token 本来不存在。训练时如果让模型偷看完整答案，它会学到不真实的捷径。

Mask 的作用就是把训练环境变得像真实生成环境。

if j > i: scoreij = -∞
35 / Cross-Attention

Decoder 要回头查 Encoder 记忆

Masked self-attention 只处理已经生成的序列。Cross-Attention 则让 Decoder 当前状态去查询 Encoder 的输出。

通俗说：写译文时，一边看已写内容，一边回头查原文。

36 / Decoder Block

Decoder 层比 Encoder 多一个交叉注意力

它通常包含：Masked MHA、Add & Norm、Cross-Attention、Add & Norm、FFN、Add & Norm。

多层堆叠后得到 Decoder 输出向量 yout。

yout = DecoderN(y<t, Xout)
37 / Logits

向量还不是词，要映射到词表长度

Decoder 输出仍然是 512 维向量，但真实输出必须来自固定词表。

所以要乘一个 512 × vocab_size 的矩阵，得到每个词的原始分数 logits。

logits = youtWvocab + b
38 / 概率分布

softmax 把 logits 变成词表概率

每个词都会得到一个概率。概率最高的词，可以通过 argmax 直接选出。

如果用采样、温度、top-p，输出会更随机、更有创造性。

39 / 生成循环

输出一个 token 后，继续预测下一个

模型不断重复：输入已有序列 → 得到概率 → 选出下一个 token → 拼回序列。

直到生成结束符，整段输出才完成。

while token ≠ <EOS>:
tokent = sample(P(v|context))
Final

把全部链路串起来

从绕口中文，到向量，到注意力矩阵，到 Encoder 理解，再到 Decoder 逐词生成。

41 / 架构差异

不是所有 Transformer 都长一样

视频最后提到：翻译类任务常见 Encoder-Decoder 结构，因为需要对齐输入和输出。

很多大语言模型更偏 Decoder-only，因为它们专注于生成下一个 token。

Encoder-Decoder：理解 + 对齐 + 生成
Decoder-only：基于上下文继续生成
42 / 为什么重要

Transformer 把语言问题变成了可并行的关系建模

RNN 时代更像按顺序读句子；Transformer 让所有 token 同时互相看见。

这使它非常适合处理长距离依赖，也为大语言模型打下基础。

核心能力：并行计算 token 关系
43 / 一句话记住

每个 token 带着问题去图书馆，按匹配度读书，最后带走加权后的理解。

这就是 Attention。多头、多层、残差、归一化和 Decoder 生成，都建立在这件事之上。
