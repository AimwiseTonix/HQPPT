01 / LLM Foundation

从一句中文
理解 Transformer

这一节只解决一个问题：大语言模型为什么能根据上下文理解一句话。我们会从中文歧义出发，依次走过 token、向量、位置、Q/K/V、图书馆类比和注意力公式。

用毒毒毒蛇，毒蛇会不会被毒毒死？
02 / 为什么需要 Transformer

语言难在“同一个词，放在不同位置含义会变”

一句话不是词语的简单堆叠。每个词的含义都由上下文决定：它前面是谁、后面是谁、它在句子里承担什么角色。

所以下一步我们先看一个中文例句。这个例句故意让同一个字重复出现，用来说明：模型真正要学习的不是单个字，而是字与字之间的关系。

这就是 attention 的直觉：不是平均阅读，而是按重要性分配注意力预算。
03 / 中文歧义例句

“毒”不是一个固定含义，而是一组上下文角色

在“用毒毒毒蛇，毒蛇会不会被毒毒死？”里，“毒”可能是名词、动词、形容词，也可能和后面的字合成“毒蛇”“毒死”。

人类能凭语境快速判断角色；模型没有直觉，只能把这种判断转成数字关系。下一页先把这些角色拆开，再进入模型如何计算。

一个好的表示，不是记录“毒=某个解释”，而是记录“这个毒在当前句子中和谁发生关系”。
04 / 角色拆解

上下文理解，首先是角色识别

“用毒”里的毒更像手段；“毒蛇”里的毒是属性；“被毒毒死”里前一个毒更像施加动作的东西，毒死是结果。

现在问题变清楚了：模型要把“角色”变成可计算的对象。第一步不是 attention，而是把文字变成模型能处理的 token。

后面所有公式，其实都在服务这件事：把角色识别变成矩阵计算。
05 / Tokenization

第一步：把句子切成模型可处理的 token

模型不能直接处理自然语言字符串。它会先把文本切成 token：有时是一个字，有时是一个词，有时是常见片段。

例如“毒蛇”“毒死”如果在语料里足够常见，就可能作为更稳定的 token 出现。切完 token 后，下一步要把这些 token 变成词表编号。

text → [token1, token2, ..., tokenn]
用毒毒毒蛇，毒蛇会不会被毒毒死？
06 / Vocabulary ID

第二步：token 不是文字，而是词表里的编号

每个 token 会映射到一个整数 ID。这个编号本身没有语义，它只是词表中的地址，用来查出下一步的向量。

可以把它理解成图书馆藏书号：编号不是书的内容，但它能准确定位到那本书。拿到编号以后，模型就可以去查 embedding 表。

tokeni → idi ∈ {0, 1, ..., |V|-1}
07 / Embedding

第三步：编号查表，得到高维语义向量

Embedding 表是一个可训练矩阵。每个 token ID 会取出一行向量，比如 512 维、768 维或更高维。

这些维度不是人手工定义的标签，而是在大量文本训练中自动形成的坐标。下一页我们把向量空间想象成一张地图，看相似用法如何靠近。

E ∈ ℝ|V|×d，xi = E[idi] ∈ ℝd
08 / 向量空间

向量不是翻译，而是“可计算的语义位置”

模型并不会把某一维解释成“毒性”“动作”“动物”。更真实的理解是：整个向量空间共同编码 token 的用法、搭配、语法和语义倾向。

当“毒蛇”和“动物”“蛇类”等用法经常共同出现，它们在向量空间里的几何关系会被训练出来。但只有语义位置还不够，模型还必须知道词的顺序。

LLM 的能力来自大量这样的向量关系叠加，而不是一条条人工规则。
09 / Position Encoding

第四步：加入位置，让模型知道顺序

Transformer 的优势是并行处理所有 token，但并行也带来一个问题：如果只给一堆向量，模型天然不知道谁在前谁在后。

所以要给每个 token 加上位置编码。直觉上，就是给每个座位贴上编号。下一页看经典 Transformer 如何用 sin/cos 给位置生成指纹。

inputi = token_embeddingi + position_embeddingi
10 / 位置编码公式

经典位置编码用不同频率的 sin / cos 形成指纹

低频曲线表达大尺度位置变化，高频曲线表达细粒度位置差异。多个频率叠加后，每个位置都会得到独特的向量指纹。

这个设计还有一个好处：相对距离会在向量模式里留下规律。到这里，输入已经变成有语义、有顺序的向量，接下来进入 Q/K/V。

PE(pos,2i)=sin(pos/100002i/d)
PE(pos,2i+1)=cos(pos/100002i/d)
11 / Q K V

同一个 token，会被投影成三种身份

加入位置信息后的输入向量 X，会分别乘以三个可训练矩阵，得到 Query、Key、Value。

这不是复制三份，而是让同一个 token 从三个角度参与计算。下一页先不看公式，用“提问、索引、正文”理解三种身份。

Q=XWQ，K=XWK，V=XWV
12 / 三种身份的直觉

Q 负责提问，K 负责被检索，V 负责提供内容

Query 像搜索请求：我现在需要什么信息？Key 像索引标签：我适合被哪类请求找到？Value 像正文内容：如果别人关注我，我真正贡献什么？

注意力机制的关键是先用 Q 和 K 算“该看谁”，再用这个结果加权读取 V。为了把这个过程讲透，接下来用四页图书馆例子一步一步对应。

过渡句：Q/K/V 可以理解成一次检索系统，Q 是搜索意图，K 是索引标签，V 是内容正文。
13 / 图书馆类比 1：带着问题进入

当前 token 先带着 Query 走进图书馆

假设当前 token 是句子里的某个“毒”。它现在不是被动等待解释，而是带着一个问题进入图书馆：我在这句话里应该参考哪些信息？

这个问题就是 Q。Q 不直接给答案，它只表达检索意图：我想找动作信息、实体信息、因果信息，还是结果信息。

承接：有了问题以后，下一步不是读书，而是先看书脊上的索引标签 K。
14 / 图书馆类比 2：匹配标签

每本书都有 Key，告诉你它适合回答什么问题

图书馆里每本书都有标签：有的书讲“毒蛇百科”，有的书讲“因果关系”，有的书讲“动作词典”。这些标签就是 K。

当前 token 的 Q 会和所有书的 K 做匹配。匹配高，说明这本书更可能对当前理解有帮助；匹配低，就暂时少看。

score(q, kj) = q · kj
15 / 图书馆类比 3：分配阅读时间

注意力权重，就是你给每本书分配的阅读比例

匹配分数还不能直接用，因为它可能是任意大小。softmax 会把分数变成一组比例，总和为 1。

这组比例就是注意力权重：例如 44% 时间读“毒蛇百科”，31% 时间读“因果关系”，17% 时间读“动作词典”。

attention weights = softmax(scores)
16 / 图书馆类比 4：带走整合理解

最后带走的不是一本书，而是加权后的新理解

你不会把一本书原封不动搬走，而是从多本书里按比例吸收内容。每本书真正贡献的正文，就是 V。

所以当前 token 的新表示 z，就是“注意力权重 × 各位置的 V”再求和。它已经包含上下文，不再是孤立 token。

zi = Σj attentionij · vj
17 / Dot Product

第一步：Q 和 K 做点积，得到匹配分数

回到数学，图书馆里的“问题匹配标签”，就是 Q 和 K 的点积。方向越一致，点积越大，说明当前 token 更应该关注那个位置。

在例句里，“用”可能会对后面的“毒”给出更高分；“被”可能更关注“毒死”这类结果信息。下一页把所有两两匹配放进矩阵。

scoreij = qi · kj
18 / Score Matrix

所有 token 两两打分，形成一张关系矩阵

如果句子有 n 个 token，每个 token 都拿自己的 Q 去匹配所有 token 的 K，就会得到 n×n 的分数矩阵。

第 i 行表示：第 i 个 token 在理解自己时，会如何看待全句所有位置。得到原始分数以后，还要先做尺度校正。

S = QKT，S ∈ ℝn×n
19 / Scale

第二步：除以 √dk，让分数保持稳定

向量维度越高，点积的数值越容易变大。如果直接送进 softmax，最大值会压倒其他值，权重过早变得极端。

除以 √dk 是一种尺度校正，让训练更稳定，也让模型在早期还能比较不同 token 的细微差别。缩放后再进入 softmax。

S = QKT / √dk
20 / Softmax

第三步：把任意分数变成总和为 1 的权重

softmax 会放大高分、压低低分，并把所有结果归一化成概率分布。这样每个 token 都有一份有限的注意力预算。

注意力权重不是“真理”，而是模型当前层学到的关系判断：这一步我应该从哪些位置吸收更多信息。最后一步就是用它读取 V。

aij = exp(sij) / Σm exp(sim)
21 / Weighted Sum

第四步：用权重读取 V，生成上下文后的新向量

有了注意力权重以后，模型会按比例读取所有 token 的 Value。高权重位置贡献更多，低权重位置贡献更少。

输出 zi 不再只是第 i 个 token 的原始含义，而是融合了全句相关信息的新表示。这一步就是图书馆例子里的“带走整合理解”。

zi = Σj=1n aijvj
22 / 完整公式

Self-Attention 的核心公式只有一行

这行公式可以读成：先用 Q 和 K 计算关系分数，缩放后用 softmax 变成权重，再用权重去加权求和 V。

Self 的意思是“自己这句话内部互相看”。每个 token 都用同一套规则，从全句中抽取对自己最有用的信息。下一页回到大语言模型。

Attention(Q,K,V)=softmax(QKT/√dk)V
23 / 回到 LLM

大语言模型的上下文能力，来自层层叠加的注意力

一层 attention 让 token 获得局部上下文；很多层叠加后，模型能组合出更抽象的语义、事实关系、语气和推理线索。

现代 LLM 通常还会使用多头注意力、残差连接、归一化、前馈网络和解码策略。但理解 Q/K/V 与加权求和，是理解后续结构的入口。最后用一句话收束整条链路。

先掌握本节课的 4 步：打分、缩放、归一化、读内容，后面的架构都会更容易。
24 / 一句话总结

每个 token 带着问题去图书馆，按匹配度读书，最后带走整合后的理解

这就是 Self-Attention：把语言里的上下文关系，变成矩阵里的权重分配，再用权重生成新的语义向量。

当这个过程在大量参数、大量文本和多层网络中反复发生，就形成了大语言模型理解上下文、续写文本和组织答案的基础能力。

文字 → token → 向量 → Q/K/V → 权重 → 新语义表示
